AI agents that know our infrastructure

I'm building Assent's CloudOps AI framework so engineers start every infrastructure repo with an agent that already knows how that repo works.

One script, a configured agent

The framework defines agents, instruction prompts and per-repository settings. A starter script sets up an agentic coding environment that follows each repo's structure and rules.

Connected to real systems through MCP

MCP connections to AWS, GitHub and Atlassian let agents import resources with context, resolve Jira tickets, review pull requests and troubleshoot AWS.

Design separate from execution

After hours: the homelab

At home I run the same kind of stack on my own hardware: an OPNsense firewall on a fibre PPPoE link, VLANs on a managed switch, Proxmox running LXC services behind Nginx Proxy Manager, Authelia for two-factor sign-in, Pi-hole for split-horizon DNS, a TrueNAS ZFS pool for storage and WireGuard for remote access.

TLS is a wildcard certificate issued through ACME DNS-01 with a CNAME alias. This site is static and deploys through GitHub Actions, so it stays up even when the lab is down.
