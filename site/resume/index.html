The homelab

At home I run the same kind of infrastructure I run at work, on a smaller budget. It's where I try things before I'd suggest them to a team.

Traffic comes in over a fibre PPPoE link to an OPNsense firewall, which also issues a wildcard TLS certificate through ACME DNS-01 using a CNAME alias. A managed switch trunks separate VLANs for wired and wireless devices. Services run as LXC containers on Proxmox behind Nginx Proxy Manager, with Authelia adding two-factor sign-in and Pi-hole providing split-horizon DNS. Remote access is over WireGuard.

Most of what I've learned came from breaking it: a corrupted ACME token, an ISP migration from DHCP to PPPoE, a failed boot SSD. Each fix ends up written down.
